# 🌌 Карта Звёздного Лорда

Инструмент для локационного отдела кино/сериалов.

**Открыть:** https://naztutnet.github.io/starlord-map/

## Возможности

- Проекты с точками на Яндекс.Картах
- Добавление точек через поиск или клик по карте
- Категории (шлагбаум, парковки, съёмочная площадка и т.д.)
- Папки / коллекции точек (создание, переименование, удаление)
- Редактирование и удаление проектов
- Генерация Call-sheet и копирование в Telegram
- **Публичная ссылка** на папку/день — карта + call-sheet без регистрации
- Экспорт / импорт проектов (JSON)
- Светлая и тёмная тема

## Как открыть

Онлайн (рекомендуется):

https://naztutnet.github.io/starlord-map/

Локально:

```bash
python3 -m http.server 8080
```

Затем: http://localhost:8080/index.html

## Статус

MVP готов к тестированию.
