# 🌌 Карта Звёздного Лорда

Инструмент для локационного отдела кино/сериалов.

## Возможности

- Проекты с точками на Яндекс.Картах
- Добавление точек через поиск или клик
- Категории (шлагбаум, парковки, съёмочная площадка и т.д.)
- Папки / коллекции точек
- Генерация Call-sheet и копирование в Telegram
- Экспорт / импорт проектов (JSON)
- Светлая и тёмная тема

## Как открыть

Лучше всего через локальный сервер:

```bash
python3 -m http.server 8080
```

Затем открой: http://localhost:8080/index.html

Или просто открой `index.html` в браузере (некоторые функции Яндекс.Карт могут требовать http).
